This tool compares pairs of areas, habitats or hosts in terms of how many taxa they share and how many unshared taxa are present in each, calculating their similarity in terms of three different indices. It works solely with the names in lists you upload and the classification they reflect. This means it works equally for plants, spiders, mammals or fungi — the names at each level come from your own columns.

Start here: press Add checklists and choose two or more CSV files. Select several files at once to load them together. Each list must include at least one column of scientific names at some rank, but to calculate similarity at different ranks it should include a column for each rank to be considered, with each column labelled to show the rank, e.g., phylum, class, order, suborder, family, genus, species. Other headers accepted for the name column: speciesBinomial (the full two-word name, not the epithet alone), scientificName, species, acceptedScientificName. Whichever ranks are present become available for comparison. Order, class and phylum are used only when your file has a column for them; the tool does not infer higher ranks from a family name. Once your files are loaded, type each region's area into the Area column of the table. Any unit works — square kilometres, hectares — as long as every row uses the same one. Taxon density is then taxa per 1,000 of that unit. Nothing is uploaded anywhere; the file runs entirely in your browser.

Jaccard = a / (a + b + c)  ·  Sørensen = 2a / (2a + b + c)  ·  Simpson = a / min(a + b, a + c), where a is the taxa shared and b, c those unique to each list. All three use presence and absence only, which is what a checklist contains. They are sensitive to how completely each area has been surveyed: an under-collected region will look less similar to everything. Taxon density is taxa per 1,000 units of the area you enter, and because the number of taxa does not rise in proportion to area, values for regions of very different size are not directly comparable.
