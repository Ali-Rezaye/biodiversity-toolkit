Checklist cleaner · any taxonomic group · runs offline

Correct names across many checklists at once — one table, applied to every file, every change reported.

Load a table of corrections — a name as it appears in your files, and its replacement — and the checklists to correct. The cleaner applies the table to every name column of every file, keeps genus and species consistent, merges rows that become the same taxon, and returns the corrected files with a full record of what changed. Headed with two rank names, the same kind of table adds a rank column instead, such as subfamily from genus. It works for any group of organisms.

Start here: 1. Load a correction table: a CSV whose first column holds names as they appear in your files and whose second column holds the replacement. Leave the second cell empty to delete every row carrying that name. 2. Add the checklists to correct — select several files at once to load them together. 3. Press Run, read the summary and the list of changes, then download the cleaned files. Your original files are never changed. Nothing is uploaded; the file runs entirely in your browser.
The cleaner applies your table exactly; it does not judge whether a correction is right. Check names first with TNRS or ChecklistBank before building the table.

Mode
Names are read with the same rules as the Phylogenetic Checklist Viewer and the Checklist Comparison: authorship is ignored when matching, so a table row without authors matches a cell with them, and the reverse. The cleaner writes UTF-8, comma-separated, one file per checklist; your originals are untouched.
